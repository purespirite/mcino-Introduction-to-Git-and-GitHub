# Simple Interest Calculator

## Project Description

The Simple Interest Calculator is a Bash-based calculator that computes simple interest using three inputs: principal amount, rate of interest, and time period.

## Formula

Simple Interest = (Principal × Rate × Time) / 100

## Input

* Principal amount
* Rate of interest
* Time period

## Output

The calculator displays the calculated simple interest based on the values entered by the user.
